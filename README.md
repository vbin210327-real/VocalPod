# VocalPod

原生 SwiftUI iPhone App，把视频（包括录屏）中的声音保存在本机反复聆听。iOS 18 或更新版本，无第三方依赖。

## 使用

1. 点击“声音库”标题右侧的「＋ 导入」，从相册或文件选择视频。
2. 提取完成后播放，可沿圆环拖动进度、切换上一首／下一首，轻点右下角图标依次切换「单曲循环」「顺序播放」「随机循环」。单曲循环默认开启；顺序播放按声音库顺序循环整份清单。随机循环每轮打乱清单、每首播放一遍，再重新打乱，避免连续重复同一首；上一首返回实际播放历史。后台和锁屏上下首同样支持随机循环。
3. 点击播放速度，选择预设或输入 0.25–3.00 之间的任意倍速。
4. 切换 App 或锁屏后继续播放；锁屏和控制中心支持暂停、上一首、下一首与进度控制。单曲和顺序模式的手动切歌按声音库顺序进行，到首尾时对应按钮停用；随机模式的下一首跟随随机队列，上一首返回实际播放历史。

其他媒体 App 播放后返回，点击播放会重新激活音频会话。缺失或延迟的系统中断通知不会卡住播放按钮；系统媒体服务重启后会重建播放器，并保留播放位置、倍速及首尾静音设置。返回前台本身不会抢占其他 App 的声音。

导入时自动识别首尾静音，播放与循环只覆盖识别后的范围，中间的停顿保留。旧音频首次打开时也会自动识别。自动跳过默认开启，无需手动剪辑或设置；旧版明确关闭的记录会在打开 App 时恢复开启。保存的音频文件始终保持不变，导出得到原音频。识别在本机进行，过于安静或无法确定边界时会保留完整范围。

主页长按声音行可拖动调整顺序，序号随新位置立即刷新，排序自动保存，重新打开 App 后保留；顺序播放和上一首／下一首按调整后的顺序运行。拖动时全部使用普通行预览，播放中高亮暂时隐藏，放下后恢复。搜索时先清除关键词再排序。声音库的更多菜单提供重命名、音频导出和删除。没有音轨的视频会明确报错。相册中的原视频不会被修改；导入的临时视频副本会清理，声音库只保存 M4A 与索引。

界面采用浅银配色：原生绘制金属圆盘、环形进度和实体感按键；声音库按编号排列，搜索按钮展开搜索框；标题右侧提供紧凑导入按钮，迷你播放器固定在底部安全区域上方。AppIcon 中五条声纹的主体宽约 72%、高约 75%，迷你播放器使用相同图标资源。原生图标几何源为 `Scripts/generate_icon.swift`。播放器和倍速面板均移除了说明性文案。

## 项目

打开 `VocalPod.xcodeproj`，选择 `VocalPod` scheme。项目生成器为 `Scripts/generate_project.py`；新增源文件或修改构建配置后运行：

```sh
python3 Scripts/generate_project.py
```

默认 Bundle ID：`com.linfanbin.VocalPod`。使用自动开发签名。

`VocalPodTests` 生成微型视频来验证实际提取、解码、持久化与播放。`VocalPodUITests` 通过 DEBUG 专用独立声音库验证交互；Release 不包含测试音频生成入口，生产数据不受测试影响。

`NowPlayingUITests` 可实际点击模拟器控制中心的上一首/下一首按钮；如果模拟器控制中心没有媒体控件，该项会明确跳过。系统指令配置与真实音频切换由 `TrackNavigationTests` 独立验证。

相册完整导入测试是可选的环境集成检查：先将生成的 1.5 秒视频 `/private/tmp/VocalPod-verification.mov` 加入模拟器相册，再运行 `testPhotosPickerImportsVideo`。未准备素材或在真机运行时，该项会跳过。

构建只复用 `/private/tmp/VocalPod-build`，交付完成后清理，不下载依赖或额外模拟器。

按要求将 App 本体目标体积设为约 50 MB。构建时由 `Scripts/size_app_bundle.py` 生成单个占位资源；App 不读取该资源，不增加功能或运行时内存占用，源码目录不保存大体积副本。

音频保存在 Application Support/VocalPod/Audio；索引为同目录 `library.json`。App 不上传音频或视频。
